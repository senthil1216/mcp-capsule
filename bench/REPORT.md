## Two-attack insight

The point of the project: sandboxing handles the first attack class but not the second; provenance handles the second.

| Attack type | Sandbox alone | Sandbox + provenance |

| Direct host secret read | blocked | blocked |
| Exfil via allowed outbound/write | not enough (already read) | approval_required, deny |
